# Мій браслет – APK releases

Lightweight Android companion app for Mi Band 7, Amazfit Bip Max and Mi Body Composition Scale 2 that works with your existing Zepp Life / Zepp account (`io.github.dmitryzemlyuk.band`). This repository holds **APK builds only**, no sources.

- **Install:** download the newest `apk/band-<version>.apk` and open it on the phone. Latest: see [`latest.json`](latest.json).
- **Updates:** the app checks `latest.json` here about once a day and offers to update through the Android system installer; the download is verified against the SHA-256 in `latest.json`. Updates install over the previous version and keep all data (same signing key).
- Only the last 3 versions are kept here; older releases and APKs are removed automatically.
- No ads, analytics or third-party SDKs. Ukrainian, Russian and English.
- Requires Android 10 or newer.
